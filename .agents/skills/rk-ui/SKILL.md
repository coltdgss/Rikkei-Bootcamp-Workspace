# /rk-ui — RK Workspace Design System Standard (V1.0)

> **Triết lý Cốt Lõi:** *Scandinavian / Swiss Minimalist & Functional Brutalism*  
> Đơn sắc (Monochrome), phẳng (Flat), sạch sẽ (Clean), ưu tiên tối đa cho việc đọc và tra cứu tài liệu học tập. Không sử dụng phong cách màu mè Cyberpunk, Neon, Dark-Blue Gradient toàn trang làm lệch tone hệ thống.

---

## 🎨 1. Bảng Màu Hệ Thống Chuẩn (CSS System Tokens)

Mọi file HTML/UI được sinh ra trong workspace **BẮT BUỘC** khai báo và sử dụng hệ biến `:root` sau:

```css
:root {
  /* Nền và Khung Bao */
  --bg-main: #f4f4f4;          /* Nền chính toàn trang / workspace canvas */
  --bg-card: #ffffff;          /* Nền thẻ nội dung, sidebar, container */
  --bg-subtle: #fafafa;        /* Nền header phụ, panel thứ cấp */
  --bg-soft: #f7f7f7;          /* Nền hover, details block, pill tag */
  
  /* Đường Kẻ & Viền */
  --line: #e5e5e5;             /* Viền mảnh mặc định giữa các phần tử */
  --line-strong: #d9d9d9;      /* Viền container, preview box */
  --line-table: #dedede;       /* Viền bảng dữ liệu */

  /* Chữ & Nhãn */
  --black: #111111;            /* Màu nhấn chính, chữ tiêu đề đậm, pill active */
  --ink: #202020;              /* Màu chữ văn bản nội dung */
  --text-muted: #777777;       /* Màu chữ phụ, mô tả, subtext */
  --text-disabled: #aaaaaa;    /* Trạng thái disabled hoặc chưa có dữ liệu */
  --white: #ffffff;            /* Chữ trên nền đen hoặc nền card */

  /* Điểm Nhấn Tinh Tế (Accents - Sử dụng tiết chế) */
  --accent-border: #111111;    /* Viền nhấn khi active / focus */
  --success-tag: #1f6b43;      /* Tag hoàn thành (xanh lá nhã nhặn) */
  --danger-tag: #b91c1c;       /* Tag cảnh báo bẫy điểm (đỏ nhạt) */
  --warning-tag: #b45309;      /* Tag chú ý (vàng nâu nhã) */

  /* ====================================================================
     TYPOGRAPHY CHUẨN (INTER & JETBRAINS MONO):
     ==================================================================== */
  --font-system: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
  --font-code: 'JetBrains Mono', Consolas, "Courier New", monospace;

  /* ====================================================================
     QUY TẮC ĐỘC TÔN (THE SACRED EXCEPTION):
     CHỈ DUY NHẤT KHỐI SOẠN THẢO / HIỂN THỊ CODE SQL MỚI DÙNG NỀN NÀY:
     ==================================================================== */
  --code-bg: #111111;          /* Nền khung gõ lệnh hoặc code SQL */
  --code-text: #f5f5f5;        /* Chữ code SQL sáng tương phản */
  --code-border: #222222;      /* Viền khung code */
  --code-font: var(--font-code);
}
```

## ⚡ 2. Quy Tắc Bất Khả Xâm Phạm (The Absolute Cardinal Rules)

1. **CHỈ CÓ KHUNG CODE SQL MỚI NỀN ĐEN:**
   - Chỉ duy nhất ô soạn thảo code SQL (`.sql-editor`, `textarea`), khối code giải bài (`.pane-code`, `pre code.language-sql`) mới được phép dùng nền đen (`#111111` hoặc `#090d16`).
   - Mục đích: Tạo điểm hội tụ thị giác tập trung (focal point) cho mắt khi đọc lệnh truy vấn database, mô phỏng đúng giao diện terminal/editor chuyên nghiệp.

2. **CẤM DARK THEME TOÀN TRANG:**
   - **Tuyệt đối CẤM** áp dụng nền tối (`#0f172a`, `#1e293b`, dark slate, cyberpunk cyan/neon) cho toàn bộ trang `body`, header, thanh tabs, danh sách bước hướng dẫn hay bảng đề thi.
   - Toàn bộ giao diện xung quanh khung code SQL **PHẢI** là nền sáng (`#f4f4f4` / `#ffffff` / `#fafafa`) để đồng bộ 100% với `Dashboard_v1`.

3. **KHÔNG AI WATERMARK:**
   - Không được tự tiện chèn emoji hào nhoáng ✨ của AI, watermark "Generated by AI" làm loãng tính chuyên nghiệp của sản phẩm.

## 🧱 3. Quy Chuẩn Các Thành Phần Giao Diện (UI Component Specs)

### 3.1. Layout & Khung Trang (Page Shell)
- `body`: `background: var(--bg-main); color: var(--ink); font-family: Arial, Helvetica, sans-serif; line-height: 1.6;`
- `container`: `max-width: 1240px; margin: 0 auto; padding: 18px 20px;`

### 3.2. Header & Banner Trang
- Nền trắng `background: var(--bg-card);`, viền `border: 1px solid var(--line);`, bo góc `8px - 10px`.
- Tiêu đề `h1`: `color: var(--black); font-size: 20px - 22px; font-weight: 800; letter-spacing: -0.04em;`
- Subtitle: `color: var(--text-muted); font-size: 12px;`
- Badge phân loại: Nền `var(--bg-soft)`, viền `1px solid var(--line)`, chữ `var(--black)`, chữ in hoa nhỏ (`10px`), `letter-spacing: .08em`.

### 3.3. Navigation Tabs (Thanh Chuyển Tab)
- Nằm trên nền sáng hoặc card trắng.
- Tab không active: Nền trong suốt hoặc `#fff`, viền xám `#e5e5e5`, chữ `var(--text-muted)` (`#777777`), font-weight 600.
- Tab active: Nền đen `var(--black)` (`#111111`), chữ trắng `#ffffff`, viền đen `var(--black)`. Bo góc `6px - 7px`.

### 3.4. Nút Bấm (Buttons)
- **Nút thường (Default / Secondary):**
  ```css
  background: #ffffff;
  border: 1px solid #d0d7de;
  color: #24292f;
  padding: 6px 12px;
  border-radius: 6px;
  font-size: 11px;
  font-weight: 700;
  cursor: pointer;
  transition: all 0.15s ease;
  ```
  Hover: `background: #f3f4f6; border-color: #111111; color: #111111;`
- **Nút hành động chính (Primary / Toggle Active):**
  ```css
  background: var(--black);
  border: 1px solid var(--black);
  color: var(--white);
  padding: 6px 12px;
  border-radius: 6px;
  font-size: 11px;
  font-weight: 700;
  ```
  Hover: `background: #333333;`

### 3.5. Split Workspace (Bài làm SQL bên trái - Đề thi bên phải)
- **Thanh Workspace Bar:** Nền `#ffffff`, viền `1px solid var(--line)`, bo góc trên `8px 8px 0 0`.
- **Nút Toggle Đề thi (Sidecar Button - phong cách Antigravity):**
  - Trạng thái mở: Nền đen `#111111`, chữ trắng `#fff` (hoặc nền trắng viền đen nổi bật).
  - Trạng thái đóng: Nền trắng `#ffffff`, viền xám `#d0d7de`, chữ xám `#666`.
  - Icon: `◧ Đóng/Mở Đề thi`.
- **Khung Trái (Bài làm SQL):**
  - Nền đen `#111111`, viền code `#222222`.
  - Chữ code `#f5f5f5`, font `Consolas, monospace`.
  - Thanh cuộn tối (`::-webkit-scrollbar-thumb` màu `#444`).
- **Khung Phải (Sidecar Đề thi):**
  - **Bắt buộc nền sáng:** `background: #ffffff;` (hoặc `#fafafa`), viền trái `1px solid var(--line)`.
  - Chữ nội dung đề: `color: #202020;`, các bảng thực thể rõ nét.

### 3.6. Bảng Dữ Liệu & ERD (Tables & Entities)
```css
.table-data {
  width: 100%;
  border-collapse: collapse;
  font-size: 11px;
}
.table-data th {
  background: #f1f1f1;
  color: #111111;
  font-size: 10px;
  font-weight: 700;
  text-transform: uppercase;
  letter-spacing: .08em;
  padding: 8px 10px;
  border: 1px solid #dedede;
  text-align: left;
}
.table-data td {
  border: 1px solid #dedede;
  padding: 7px 10px;
  color: #333333;
}
.table-data tr:hover td {
  background: #fafafa;
}
```

### 3.7. Callouts & Hộp Ghi Chú (Notes & Alerts)
- **Ghi chú chuẩn:**
  ```css
  .rk-note {
    padding: 10px 14px;
    border-left: 3px solid #111111;
    background: #f7f7f7;
    color: #444444;
    font-size: 11.5px;
    border-radius: 0 6px 6px 0;
    margin: 10px 0;
  }
  ```
- **Cảnh báo lỗi / Bẫy điểm thi:**
  Viền trái đỏ gạch `#dc2626`, nền hồng phấn rất nhạt `#fef2f2`, chữ `#991b1b`.

## 📋 4. Checklist Thẩm Định Trước Khi Render (/rk-ui Audit)

Trước khi xác nhận hoàn thành bất kỳ file UI nào, Agent phải tự rà soát:
- [ ] Toàn trang có dùng nền sáng `#f4f4f4` / `#ffffff` không?
- [ ] Đã loại bỏ hoàn toàn các màu tối gradient (`#0f172a`, `#1e293b`) khỏi Header, Body, Tabs, Sidecar chưa?
- [ ] Chỉ duy nhất khung code SQL là mang nền `#111111`?
- [ ] Font chữ chính là `Arial, Helvetica, sans-serif` và font code là `Consolas, monospace`?
- [ ] Nút bấm, tab, badge có đúng quy chuẩn đen/trắng tối giản không?
- [ ] Bảng dữ liệu có header xám sáng `#f1f1f1` và viền `#dedede` sắc nét không?
