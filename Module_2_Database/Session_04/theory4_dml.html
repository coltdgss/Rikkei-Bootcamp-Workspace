Session 04 · Data Manipulation Language

Lý thuyết cốt lõi: Nhóm lệnh DML & Truy vấn cơ bản

Nội dung học tập được đồng bộ trực tiếp từ giáo trình RK-MODULE2-DATABASE trên Google Drive. Làm chủ thao tác dữ liệu: INSERT, UPDATE, DELETE và cấu trúc SELECT đa điều kiện.

1. Tổng quan về DML (Data Manipulation Language)

DML là tập hợp các lệnh SQL dùng để thao tác trực tiếp trên dữ liệu bên trong các bảng của cơ sở dữ liệu. Khác với DDL (tạo và sửa cấu trúc bảng), DML chỉ thay đổi nội dung dữ liệu mà không làm biến đổi cấu trúc cột hay kiểu dữ liệu.

4 câu lệnh DML trụ cột:
• INSERT: Thêm bản ghi mới vào bảng.
• UPDATE: Cập nhật, sửa đổi giá trị các dòng dữ liệu có sẵn.
• DELETE: Xóa một hoặc nhiều bản ghi ra khỏi bảng.
• SELECT: Truy vấn, đọc và hiển thị dữ liệu từ một hoặc nhiều bảng.

2. Thao tác Thêm, Sửa, Xóa dữ liệu (INSERT, UPDATE, DELETE)

2.1. Lệnh INSERT INTO

Dùng để chèn một hoặc nhiều dòng mới vào bảng. Thứ tự giá trị trong mệnh đề VALUES phải tương ứng chính xác với thứ tự các cột được liệt kê.

SQL DML · INSERT INTO
-- Chèn 1 dòng chỉ định rõ cột
INSERT INTO students (student_id, full_name, birth_date, gender, email)
VALUES ('SV001', 'Nguyen Van A', '2004-05-12', 'Nam', 'vana@gmail.com');

-- Chèn nhiều dòng cùng một câu lệnh
INSERT INTO students (student_id, full_name, birth_date, gender, email) VALUES
('SV002', 'Tran Thi B', '2005-11-20', 'Nu', 'thib@gmail.com'),
('SV003', 'Le Hoang C', '2003-08-15', 'Nam', NULL); -- Email có thể để trống (NULL)

2.2. Lệnh UPDATE

Dùng để chỉnh sửa dữ liệu đã có. Mệnh đề WHERE xác định dòng nào cần được sửa.

⚠️ CẢNH BÁO TỬ HUYỆT: Nếu quên mệnh đề WHERE, MySQL sẽ cập nhật TOÀN BỘ CÁC DÒNG trong bảng mà không thể hoàn tác!
SQL DML · UPDATE
-- Cập nhật email cho sinh viên có mã SV003
UPDATE students
SET email = 'hoangc_updated@gmail.com'
WHERE student_id = 'SV003';

-- Cập nhật đồng thời nhiều cột
UPDATE students
SET full_name = 'Le Hoang C VIP', gender = 'Nam'
WHERE student_id = 'SV003';

2.3. Lệnh DELETE

Dùng để xóa một hoặc nhiều bản ghi dựa vào điều kiện lọc.

⛔ NGUY HIỂM: Câu lệnh DELETE FROM students; (không có WHERE) sẽ xóa sạch toàn bộ dữ liệu trong bảng!
SQL DML · DELETE
-- Xóa một bản ghi cụ thể theo khóa chính
DELETE FROM students
WHERE student_id = 'SV002';

3. Truy vấn dữ liệu cơ bản (SELECT, WHERE, ORDER BY, LIMIT)

3.1. Cú pháp SELECT cơ bản

Hai từ khóa tối thiểu là SELECT (lấy cột nào) và FROM (từ bảng nào).

SQL Query · SELECT & Alias
-- Xem tất cả cột (*)
SELECT * FROM students;

-- Chỉ lấy các cột cần thiết và đặt bí danh (Alias AS)
SELECT student_id AS MaSV, full_name AS HoVaTen, email
FROM students;

3.2. Lọc dữ liệu với WHERE, AND, OR, BETWEEN, IN, LIKE, IS NULL

SQL Query · Các toán tử điều kiện lọc
-- 1. Lọc khoảng với BETWEEN
SELECT * FROM students
WHERE birth_date BETWEEN '2003-01-01' AND '2005-12-31';

-- 2. Lọc trong danh sách với IN
SELECT * FROM students
WHERE student_id IN ('SV001', 'SV003', 'SV005');

-- 3. Tìm kiếm chuỗi tương đối với LIKE (Họ bắt đầu bằng 'Ng')
SELECT * FROM students
WHERE full_name LIKE 'Ng%';

-- 4. Kiểm tra rỗng với IS NULL / IS NOT NULL
SELECT * FROM students
WHERE email IS NULL;

-- 5. Kết hợp nhiều điều kiện AND / OR / NOT
SELECT * FROM students
WHERE (gender = 'Nam' OR gender = 'Nu') AND email IS NOT NULL;

3.3. Sắp xếp ORDER BY và Phân trang LIMIT - OFFSET

SQL Query · ORDER BY & LIMIT
-- Sắp xếp giảm dần theo ngày sinh (trẻ nhất lên đầu)
SELECT * FROM students
ORDER BY birth_date DESC;

-- Lấy 3 bản ghi đầu tiên
SELECT * FROM students
ORDER BY birth_date DESC
LIMIT 3;

-- Phân trang: Bỏ qua 2 bản ghi đầu (OFFSET 2), lấy 5 bản ghi tiếp theo
SELECT * FROM students
LIMIT 5 OFFSET 2;
